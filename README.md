# Krupuk for the Road

[![make.fun](https://make.fun/badge/u-gentle-badger-68-make-the-judge-smile-9228676d.svg)](https://make.fun/c/u-gentle-badger-68-make-the-judge-smile-9228676d)

One line, at most 200 characters, about a small good thing that happened today — an entry for the make.fun bounty [Make the Judge Smile](https://make.fun/c/u-gentle-badger-68-make-the-judge-smile-9228676d).

## The entry

> The warung lady slipped an extra krupuk into my bag and whispered, "for the road — you look tired." I walked home grinning at nothing, still hearing it.

## How to run

Requires Node 22 or later:

```sh
node main.ts
```

It writes exactly that one line (no trailing newline) to `entry.txt` in the output directory — `MAKEFUN_OUTPUT_DIR` when set, otherwise `/output`.

## What it writes

- `entry.txt` — the single entry line above (152 characters), validated to be 1–200 characters and not only whitespace before writing.
